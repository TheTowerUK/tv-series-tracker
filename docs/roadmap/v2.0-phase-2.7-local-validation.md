## Security and deployment gate

Local browser configuration uses only the local URL and publishable key and remains ignored. The TMDB read-access token remains only in ignored `supabase/functions/.env.local`; it is neither committed nor rendered. `tmdb-search-tv` is authenticated-only, has no tracker database or service-role dependency, uses fixed upstream parameters, and records no query history or analytics.

The hosted development project remains untouched. Any future `supabase login`, `supabase link`, hosted migration inspection or push, hosted secret configuration, Edge deployment, Auth configuration, or GitHub Pages change requires explicit project-owner approval and a separate validation record. Staging and production remain deferred.
