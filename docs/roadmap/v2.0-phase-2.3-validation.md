## Concurrency harness

[`run-rpc-races.ps1`](../../supabase/tests/concurrency/run-rpc-races.ps1) opens two independent local PostgreSQL sessions for each race. Session A performs the mutation inside an uncommitted transaction and pauses; Session B observes the pre-commit state and contends on the unique index. After Session A commits, the losing function must normalize the database race to the same safe public result used for an ordinary collision.

The harness uses synthetic Auth identities and deletes them afterward. It accepts a Docker executable path for environments where Docker is not on `PATH`. It targets only the local container named from the repository `project_id`; it does not link to or contact a hosted project.
